# Raghunath N — Portfolio

A personal portfolio for **Raghunath N**, an AI engineer, full-stack developer, and creative technologist. The site brings together selected projects, AI research, engineering capabilities, leadership work, and creative interests in an interactive experience.

**Live site:** [raghunath.dev](https://raghunath.dev)

## Highlights

- Selected work spanning AI/ML, computer vision, full-stack development, systems, and creative technology
- AI research lab and interactive project visualizations
- Interactive developer terminal and command palette
- Dark/light theme support, custom cursor, and responsive layouts
- Profile, skills, achievements, and project content maintained in the `data/` directory

## Built with

- [Next.js](https://nextjs.org/) 15 and React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React

## Getting started

### Requirements

- Node.js 18.18 or later
- npm

### Install and run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run the project's lint script |

## Project structure

```text
app/          Next.js routes, layout, and global styles
components/   Portfolio sections and interactive UI
data/         Profile, projects, skills, achievements, and content
```
